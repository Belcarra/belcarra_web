Driver Overview

Belcarra USBLAN for Windows is a USB Class driver used to create and manage a USB networking link between a Windows host and an OEM device using industry-standard USB networking protocols.

When a matching device is connected, USBLAN loads for the network function and creates a virtual network interface that operates like an Ethernet interface over the USB link.

Current primary target

  • Windows 11 amd64
  • Windows 11 arm64

Protocol coverage

  • CDC-NCM
  • CDC-EEM
  • CDC-ECM
  • RNDIS

Operational model

  • For each connected device instance, USBLAN creates a Layer 2 network interface over USB transfer frames.
  • Plug-and-play installation from a local driver store or Windows Update (based on kit configuration).
  • Optional built-in DHCP service to coordinate host/device IPv4 addressing on point-to-point USB segments.
  • Supports composite devices by matching the interface (MI) for the network sub-function.

Engineering features

  • IPv4 and IPv6 support
  • Power management support (sleep, standby, hibernation, resume)
  • Microsoft hardware certification workflow compatibility
  • Multiple simultaneous USB devices (up to sixteen per host)
