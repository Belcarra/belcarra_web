Send an Inquiry

Complete the form below to reach the Belcarra engineering and licensing team. Refer to the checklists below for suggested details to include.

Inquiry Checklists

To help our engineering team review and respond to your request efficiently, please include the relevant details in your Message Details above:

Commercial Licensing & Evaluation

  • Company name and hardware product context
  • Target Windows platform (Windows 11 amd64 or arm64; Windows 10 amd64)
  • Required USB networking protocol (CDC-NCM, CDC-EEM, CDC-ECM, RNDIS)
  • Anticipated production volume and evaluation schedule
  • Any specific Microsoft driver signing or compliance constraints

Technical Support & Integration

  • Host Windows version/build and architecture (amd64 or arm64)
  • USBLAN driver package version and INF configuration
  • Device USB controller, firmware version, and protocol mode
  • Composite USB interface numbering and configuration
  • Observed behavior, error codes (e.g., Code 10, 28, 43), and reproduction steps or logs

Security & Vulnerability Disclosures

When reporting a security concern, select security@belcarra.com in the Send To menu above.

  • Detailed description of the issue and affected driver or software version
  • Step-by-step reproduction instructions or proof of concept
  • Impact assessment and any coordinated disclosure timeline expectations
