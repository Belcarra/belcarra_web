FAQ

Who is this solution designed for?

Belcarra USB networking solutions target OEM and enterprise engineering teams building hardware products that require stable networking-over-USB support.

What host platforms are currently prioritized?

Current focus is Windows 11 on amd64 and arm64.

Which USB networking protocols are supported?

USBLAN supports CDC-NCM, CDC-EEM, CDC-ECM, and RNDIS.

Can this be used with composite USB devices?

Yes. Composite support is based on matching the relevant network interface (MI), with stable interface numbering recommended for predictable host binding.

How are IP addresses handled on USB links?

Deployments can use DHCP or static addressing. USBLAN configurations can include built-in DHCP behavior for point-to-point USB networking scenarios where appropriate.

What should be included in a support request?

  • Windows build/version and architecture
  • Driver package version
  • Device firmware version and protocol mode
  • Clear reproduction steps and observed behavior
  • Relevant host/device logs

How is this website maintained?

Tabbed documentation pages are plain HTML for direct editing. Announcements are Markdown files listed in announcements/manifest.json.
