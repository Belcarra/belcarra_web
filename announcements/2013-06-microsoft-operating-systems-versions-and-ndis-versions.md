Belcarra published a mapping reference between Microsoft operating systems and NDIS versions.

This reference is useful when planning compatibility and deciding which behavior assumptions apply to a given host platform. Understanding NDIS-level differences helps engineering teams avoid invalid comparisons across Windows generations.

For USB networking programs, a clear OS-to-NDIS map improves triage quality and reduces confusion when evaluating reports from mixed customer environments.

Recommended use:
- Include the map in internal support runbooks.
- Tie validation matrices to OS and NDIS expectations.
- Use it when scoping minimum supported platform baselines.
