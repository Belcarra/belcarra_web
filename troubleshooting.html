Troubleshooting

Use this page as an engineering runbook for isolating host/device USB networking issues on Windows 11 systems.

Baseline capture

  • Host OS version and architecture (amd64 or arm64)
  • Device firmware/build and USB descriptors
  • Selected protocol mode (RNDIS, ECM, EEM, NCM)
  • Driver package version currently installed

Common issue patterns

Device enumerates but no network interface appears

Likely causes: protocol/interface mismatch, missing/incorrect package binding, or composite interface selection mismatch.

Verify: check Device Manager instance details, interface IDs (including MI), and active driver binding.

Resolve: correct INF/device matching, reinstall intended package, reconnect and confirm adapter creation.

Interface appears but no IP connectivity

Likely causes: address assignment failure, DHCP behavior mismatch, host/device firewall policy, or gadget-side link-state handling.

Verify: capture host IP configuration and route table, confirm device-side addressing and gateway expectations.

Resolve: align host/device addressing model, validate DHCP/static policy, retest with controlled subnet settings.

Throughput lower than expected

Likely causes: suboptimal transfer aggregation, protocol selection mismatch, power policy throttling, or device firmware bottlenecks.

Verify: compare behavior across RNDIS/ECM/EEM/NCM where supported, test sustained transfer scenarios, review power state transitions.

Resolve: tune protocol/transfer configuration and confirm stable behavior after sleep/resume and reconnect cycles.

Intermittent disconnects after sleep/resume

Likely causes: host power policy interaction, firmware resume timing, or stale adapter state after wake.

Verify: reproduce with controlled suspend/resume cycles and collect system/device event logs.

Resolve: apply power-policy adjustments, validate firmware timing, and confirm recovery with repeated wake cycles.

Recommended evidence bundle

  • Host build/version, architecture, and driver package identifiers
  • Protocol mode and descriptor snapshot for failing device
  • Step-by-step reproduction sequence
  • Expected result vs observed result
  • Relevant host/device logs around failure window
