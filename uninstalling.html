Uninstalling

Use this procedure to remove USBLAN driver instances and related driver packages on Windows 11 lab and support systems.

Scope

  • Windows 11 amd64
  • Windows 11 arm64
  • Single or multiple attached USB networking devices

Standard removal sequence

  • Disconnect the target device when possible to avoid immediate re-enumeration.
  • Remove the installed device instance from Device Manager (or equivalent scripted workflow).
  • Enumerate matching driver packages in the driver store.
  • Delete the target package from the driver store when complete uninstall is required.
  • Reconnect device only after confirming expected package/version state.

Command-line workflow (example)

For scripted support, use pnputil to inspect and remove packages. Validate package identity before deletion.

pnputil /enum-drivers
pnputil /delete-driver oemXX.inf /uninstall /force

Verification checklist

  • Target device instance no longer references the removed package.
  • No stale network adapter entries remain for removed instances.
  • Reinstall path loads the intended package version.
  • Post-reinstall link and IP behavior are validated.

Partial uninstall recovery

  • If the package remains in the store, repeat package enumeration and removal with elevated permissions.
  • If stale adapters remain, remove hidden/non-present device instances and rescan hardware.
  • If automatic reinstall picks an unintended package, pin the intended package in your deployment flow before reconnecting.
